# Agon

Private Trainings-Web-App fürs iPhone zum Greek God Program 2.0 (Kinobody). Training an drei Tagen pro Woche, Satzführung mit Pausen-Countdown, Statistik und griechische Ränge bis zum Gott.

Installation: Seite in Safari öffnen, Teilen-Menü, «Zum Home-Bildschirm».

Die Trainingsdaten bleiben lokal auf dem Gerät. Agon steht in keiner Verbindung zu Kinobody.
